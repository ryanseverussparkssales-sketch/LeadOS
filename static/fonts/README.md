# Miller Banner Light

Purchase from myfonts.com → download the webfont kit → place files here:

  MillerBanner-Light.woff2
  MillerBanner-Light.woff
  MillerBanner-LightItalic.woff2
  MillerBanner-LightItalic.woff

Until licensed, Playfair Display (loaded via Google Fonts) is the fallback
and is visually very close. The @font-face in app.css will silently
ignore a missing file — no build errors.
