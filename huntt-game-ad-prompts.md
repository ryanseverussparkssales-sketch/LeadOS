# Huntt Creator Ads — Visual Direction + Canva Prompts

**Platform:** creators.huntt.gg — "Promote the coolest drops. Better affiliate revenue."
**Use:** Facebook + Reddit ad slides, one set per game.

---

## Read this first (assets + licensing)

AI image tools (Canva Magic Media, etc.) **will not** render trademarked characters or logos — and you shouldn't bake them into paid ads unless you have the right to use them. So the workflow below is built in two layers:

1. **Background / scene** — generated from the Canva prompt (genre vibe, no trademarked IP). Safe.
2. **Official asset overlay** — drop the game's *official* logo or key art on top, sourced from the asset you're cleared to use (the game's offer/affiliate brand kit, or its public press kit). This keeps Meta/Reddit ad review and the publishers happy.

Each game below lists the **3 most recognizable elements** to feature and **where the official asset lives**. If these games are live offers on Huntt, pull the approved creative from the offer's brand kit first — that's your cleanest, fully-licensed source.

**Brand styling to keep consistent across every slide (paste into any prompt):**
> Dark near-black navy background with electric cyan (#29B6E8) glow accents and subtle tech grid; bold heavy condensed white headline; clean modern sans body text; the Huntt cyan plus-sign (+) logo and "creators.huntt.gg" wordmark in the lower-right corner; 1200x628 horizontal ad, high contrast, premium gaming look.

For each game you get **two prompts**:
- **A — Streamer Partnership** (recruit creators: "promote this drop, earn more")
- **B — Platform Promo** (sell Huntt itself: "the coolest brands, exclusive drops")

## How to use these in Canva
1. New design → **Custom size 1200 x 628 px** (Facebook/Reddit link ad).
2. **Magic Media → Text to Image** → paste a prompt's scene description to generate the background.
3. Add a dark overlay + the brand styling (cyan accents, headline, "creators.huntt.gg", the + logo).
4. Drop the **official game logo/art** (from the licensed source) into the reserved space.
5. Export PNG. Duplicate the page for the A/B variant.

**Reddit vs Facebook caption tone:** keep the slide identical, change the post copy. Reddit = blunt, streamer-to-streamer. Facebook = polished/aspirational. Ready-to-use captions for each game are in the section below.
